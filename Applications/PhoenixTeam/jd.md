Senior Software Engineer, AI-First Development
Fully Remote • Arlington, VA

Job Type
Full-time
Description


PhoenixTeam is hiring three Senior Software Engineers to build and support production software for the Department of Veterans Affairs (VA). The work includes services, tools, and integrations, primarily in Python, with AI coding agents such as Claude Code serving as the primary implementation method.



This role requires an established software engineering background and the ability to work independently of AI tools when necessary. Engineers must be able to understand unfamiliar codebases, make architectural decisions, troubleshoot failures, and reason about performance, concurrency, and system behavior. Coding agents accelerate implementation, but the engineer remains responsible for the quality and reliability of the software delivered.



The Senior Software Engineer directs and verifies agent-driven development, corrects errors in generated code, and improves the workflows used to complete recurring engineering tasks. The position works closely with the Chief AI Engineer, QA & Evals, DevSecOps, Platform, and client delivery teams to move software from development into production.



Key Functions

Design, build, and deliver production services, tools, and integrations, primarily in Python, using AI coding agents as the primary implementation method.
Translate ambiguous requirements into defined engineering tasks, acceptance criteria, and verification steps that agents can execute.
Own the architecture, testing, security, performance, and operational readiness of assigned software components.
Independently review, test, and correct agent-generated code, including edge cases, failure handling, and potential regressions.
Develop automated tests, evaluations, and acceptance checks to verify correctness and maintain software quality.
Investigate and resolve technical issues using debuggers, profilers, logs, and underlying library source code.
Create reusable agent skills, workflows, instructions, and runbooks for recurring engineering tasks.
Improve agent context, prompts, and tool access while measuring development cycle time, defect rates, and review rework.
Collaborate with QA & Evals, DevSecOps, Platform, and client delivery teams on production readiness, quality, and security requirements.
Document technical decisions, implementation details, verification results, and handoffs for engineering and client stakeholders.
Make implementation and code-acceptance decisions within assigned components while escalating cross-system changes and unresolved security, data, or quality concerns.
What Success Looks Like

First 30 days: Deliver an initial production change through the standard pipeline, subject to required system access, and demonstrate effective use of the team's coding agents.
First 60 days: Own an assigned component and establish at least one reusable engineering workflow adopted by other team members.
First 90 days: Deliver a feature or client deliverable primarily through coding agents, supported by independently verified tests and evaluations, with review rework trending down.
First year: Establish ownership of a defined technical area, with reusable workflows adopted as standard team practices and readiness for assessment at the next level.
