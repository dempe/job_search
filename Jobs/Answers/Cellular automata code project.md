```
https://github.com/dempe/cellular-automata

This is some code that I wrote about 8 years ago. It generates images (pre-built in repo) of 256 one-bit celular automata (one bit meaning that each cell is either on or off). Each line on each of the images is a new generation determined from the preceding generation such that each cell's state is determined by the state of the cell directly above it and to the top right and top left of it. The first generation is simply a "seed generation" with all cells off except the middle cell.

These cellular automata represent the surprising complexity that arises from very simple rules. And many of these patterns can even be found in real life!
```
