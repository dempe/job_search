>  Got it. What's something technically challenging you're working on right now that's pushing your skills?

```
i'm currently building a react native app in typescript. as mentioned, my background is nearly 100% backend, so this frontend work has been terra incognita for me. a lot of it was getting familiar with the tooling, but it was also much more than that. there's a lot of paradigms and patterns that you need to wrap your head around like react's declarative model, state management in react, and how data flow and rendering interact over time. i've primarily used imperative languages, so reasoning about state, effects, and re-renders has required a real shift in how i think about code (which is a skill transferable to my backend work as well). I've already got one app live and out the door! currently working on the next one. working with a live app means dealing with performance, persistence, and user-facing edge cases. all this has forced me to confront gaps in my understanding and close them systematically.
```

## Recidiviz

Source: [[Recidiviz]]

> In 2-3 sentences, describe the most recent full-stack project you worked on.(Required)

```
My most recent full-stack project is Athena Math, a mobile app I built with React Native, TypeScript, and Expo on the client side, backed by an AWS serverless architecture (API Gateway, Lambda, DynamoDB, S3/CloudFront), all defined with SAM templates. I implemented CI/CD with GitHub Actions, CloudFormation-backed rollbacks, operational monitoring through CloudWatch, and a retry system using SQS for reliability. It's a fully shipped production app now live in the App Store: https://apps.apple.com/us/app/athena-math/id6747783222
```
